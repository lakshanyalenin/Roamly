## 📌 About the Project

**Roamly** is a modern travel exploration and trip-planning website designed to make travelling easier, smarter, and more enjoyable.

It brings destination discovery, hidden-gem recommendations, personalised itinerary planning, and travel budget estimation together in one platform.

Whether someone is planning a short getaway or a longer vacation, Roamly helps them explore destinations, organise their journeys, and understand their estimated travel expenses before setting off.

The website features a modern interface with a travel-inspired design, interactive elements, and dark/light theme support.

## ✨ Key Features

### 🌍 1. Destination Discovery
- Explore curated travel destinations.
- Browse destination photography and travel information.
- Discover new places for your next adventure.

### 💎 2. Hidden-Gem Recommendations
- Explore lesser-known travel destinations.
- Discover local attractions and off-the-map spots.
- Access useful local travel tips.

### 🗺️ 3. Personalised Trip Planner
- Select your preferred destination.
- Set the duration of your trip.
- Choose the number of travellers.
- Select a travel style:
  - Backpacker
  - Budget
  - Comfortable
  - Luxury
- Explore sample day-by-day itineraries with suggested activities and schedules.

### 💰 4. Budget Estimation
- Estimate overall trip expenses.
- View estimated costs in Indian Rupees (INR).
- Calculate approximate per-person expenses.
- Access a detailed budget calculator.

### 📖 5. Travel Stories
- Explore the travel stories section.
- Find inspiration for future journeys.

### 🎨 6. User Experience
- Modern and responsive interface.
- Dark and light theme toggle.
- Easy navigation between website sections.
- Destination search functionality.
- Newsletter subscription section.

## 🚀 Getting Started

Follow these instructions to run Roamly on your local machine.

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/lakshanyalenin/Roamly.git
```

**2. Navigate to the project directory**

```bash
cd Roamly
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal (usually `http://localhost:5173`) in your browser.

It aims to encourage travellers to explore beyond popular tourist destinations while making their travel planning experience more organised.
